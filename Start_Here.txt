DEADLOCK DOLLY 0.4.4 ALPHA — SOURCE PACKAGE

A camera-path editor for local Deadlock replays.

THIS MOD INJECTS CODE INTO DEADLOCK — USE AT YOUR OWN RISK.
Native mode loads a user-mode DLL for camera rendering and in-game controls.
It does not install a kernel driver.

KEEP -insecure IN DEADLOCK'S LAUNCH OPTIONS WHILE USING DOLLY.
The launcher also adds -dev -insecure -console to its editing session.
Close that session before launching Deadlock normally.

This source package includes the Windows native helper. Run Launch_Dolly.bat
or python -m dolly with Python 3.10+ and Tcl/Tk. Windows EXE builds are covered
in docs/BUILDING.md. The Windows portable ZIP includes Python and opens through
Dolly.exe; keep its _internal folder beside it.


GETTING STARTED

1. Open Steam, sign in, and close any running Deadlock game. Use DirectX 11.
2. Open Dolly. On Home, choose Deadlock's executable and a local, extracted
   .dem replay. Replays lists demos from the selected replay folder.
3. Click Play replay. Dolly initializes the unlocker in the hideout before
   loading the replay, then pauses it with native camera controls ready.
4. Move to the first view and press Ctrl+Alt+K. Advance the replay, frame the
   next view and capture again. F8 opens capture, saved views and playback.
5. On the desktop Cameras tab, edit framing, camera bank and arrival times.
   Replay timing is selected by default and uses the replay tick at capture.
   Timed shot is optional for placing multiple views at one paused moment.
6. Click Play shot or press F5. Dolly returns to the shot's start, applies the
   camera and supported DOF settings, then plays the replay and path together.
   Hide HUD controls HUD visibility during playback; it returns afterward.
7. Save the shot from the desktop File menu. Effects contains the depth-of-field
   preset and camera-variable tracks. More > Coordinates / timing on Cameras
   opens the advanced camera settings.


DEFAULT CONTROLS

Ctrl+Alt+K     Capture camera; the first capture starts the shot
Ctrl+Alt+R     Replace selected camera
P             Pause/resume replay
F5 / F6       Play path / Stop and restore
PageUp/Down   Previous/next saved camera
Comma/Period  Seek backward/forward one second
F7            Open/close console
F8            Toggle Dolly panel
F9            Switch to/from Deadlock's replay UI for hero selection
F10           Enter paused flight from Dolly's panel or a held view
WASD          Move relative to the camera
Space/Ctrl    Move up/down
Mouse/arrows  Look around
Shift/Alt     Move faster/slower
Q/E           Camera roll

Keybinds saves keyboard and Mouse4/Mouse5 assignments, movement speed and mouse
sensitivity. F7 is reserved for the console. Settings are stored in
%APPDATA%/DeadlockDolly/settings.json and survive program-folder updates.

The console receives normal typing without moving the camera or triggering
Dolly shortcuts. F7 or Escape closes it and returns to the previous UI.
F8 closes the console and opens the Dolly panel.
From Deadlock's replay UI, F8 returns to the panel and F9 returns to flight.
Returning hides both the replay controls and character HUD. F9 shows them again.
Release held movement keys after switching windows before pressing them again.


CAMERAS, FRAMING AND PLAYBACK

Native capture uses the displayed camera position, rotation and framing.
Capture also works while the replay is playing and leaves it paused.
The in-game capture key saves the rendered view and tick at the keypress.
Desktop capture waits for a paused rendered view before saving its tick.

Previous/next and saved-view preview change the camera at the CURRENT paused
replay moment. They do not seek to that camera's arrival time. F10 continues
flight from the displayed view.

Framing uses r_aspectratio. Normal starts at 16:9 (about 1.77778). Select a
camera and drag its point in FRAMING CURVE, or enter Aspect ratio and click
Update camera. Preview applies the selected view. Smooth, Linear and Step
framing curves are available. These values are ratios, not FOV degrees.

Timed shot allows several camera captures at one paused replay moment.
Replay timing assigns arrival times from replay ticks. The first capture sets
the shot's start tick. Ticks/second defaults to 64 and is also used for seeking.
Replace selected changes a camera's pose at its existing arrival time.

Speed changes the replay and camera together: a four-second shot at 0.1x takes
about forty real seconds. Frozen preview moves along the path while the scene
stays paused. Stop / restore releases the camera and restores its settings;
the game's spectator view may be elsewhere.

Supported native DOF curves run at the same rendered-view phase as the camera.
The seven supported controls are listed in docs/NATIVE_EFFECTS.md. Updates / s
sets the monitoring rate in Native mode. Playback smoothing applies only to
Console (legacy).


COMPATIBILITY

Native mode supports reviewed client.dll, engine2.dll and tier0.dll builds.
A Deadlock update can require a Dolly update. Home > Troubleshooting contains
the manual startup controls and Console (legacy) driver.

0.4.4 is an alpha. The DX11 vertex-buffer crash remains under investigation.
This update fixes temporary-session cleanup and adds read-only graphics diagnostics.
ReShade compatibility is unverified. In-world path markers, full
in-game curve editing and video/render-pass export are planned for later updates.
Technical details and validation results are in docs/VALIDATION.md.


UPDATING AND RECOVERY

Close Deadlock and Dolly before updating. If the old installation has a pending
gameinfo recovery, use its Recover_Game_Config.bat first. Keep saved shots and
logs, including any recovery backup. Use the complete new package; 0.4.4 uses
ABI 3 and its native helper must match the editor.

After an interrupted launch, close Deadlock and use File > Recover game
configuration or Recover_Game_Config.bat. The portable app also supports:
  Dolly.exe --recover


SESSION FILES

The game/citadel_dolly_... folder is created per editing launch, not by a
diagnostic export. Dolly restores the original gameinfo.gi after unlocker
initialization and removes the temporary plugin folder when Deadlock exits.
If Dolly closes first, a background helper waits for that exact game process,
removes its generated files and exits. Loaded DLLs cannot be removed while
the game still uses them. Close the editing game before a normal Steam launch.

The next Dolly launch also checks marked leftovers from older versions.
With Deadlock closed, File > Recover game configuration runs that cleanup
without starting a game. Configuration conflicts and unrecognized files are
left untouched. Keep logs and original backups for diagnostics/recovery;
personal settings and saved shots are not removed.
