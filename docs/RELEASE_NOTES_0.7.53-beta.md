### Deadlock Dolly v0.7.53-beta

**0.7.53-beta**

- **Works with the November 23 Deadlock update.** *Before:* after the November 23 Deadlock update (build 6865), Dolly refused to start a replay because the new game build had not been reviewed. *After:* Dolly supports build 6865 again, including the native camera, Follow, gameplay effects, and particles.

- **Updated cvar unlocker for the new game build.** *Before:* the previous cvar unlocker rejected build 6865's updated server binary at startup. *After:* Dolly ships an updated cvar unlocker matched to build 6865 while keeping support for earlier reviewed builds.
