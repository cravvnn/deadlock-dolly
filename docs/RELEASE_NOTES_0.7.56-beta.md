### Deadlock Dolly v0.7.56-beta

**0.7.56-beta**

- **Works with the November 24 Deadlock update.** *Before:* after the November 24 Deadlock update, Dolly refused to start a replay because the new game build had not been reviewed. *After:* Dolly supports the new build again, including the native camera, Follow, gameplay effects, particles, Players exports and recorded game audio.

- **Updated cvar unlocker for the new game build.** *Before:* the previous cvar unlocker rejected the updated game server at startup. *After:* Dolly ships an updated cvar unlocker matched to the new build while keeping support for earlier reviewed builds.
